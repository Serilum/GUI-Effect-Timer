<p><strong><span style="font-size: 24px;">Requires the library mod&nbsp;<a style="font-size: 24px;" href="https://curseforge.com/minecraft/mc-mods/collective" target="_blank" rel="noopener noreferrer">Collective</a>.<br /></span></strong></p>
<p><span style="font-size: 18px;">GUI Effect Timer is a client-side mod that adds timers to the bottom of effect badges on the screen.&nbsp;It works with abbreviations for seconds, minutes, hours and days. Updated every tick, it allows you to see the exact moment your effects run out. Very handy for when you're in lava with fire resistance!<br /><br />The text colour is easily changed within the config. White by default.<br /></span><br /><br /><strong><span style="font-size: 20px;">Configurable:</span> <span style="color: #008000; font-size: 14px;"><a style="color: #008000;" title="how" href="https://github.com/Serilum/.information/wiki/how-to-configure-mods" target="_blank" rel="noopener noreferrer">(&nbsp;how do I configure?&nbsp;)</a></span><br /></strong><span style="font-size: 12px;"><strong>timerColourRGB_R</strong>&nbsp;(default = 255, min 0, max 255): The red RGB value for the timer text.</span><br /><span style="font-size: 12px;"><strong>timerColourRGB_G</strong>&nbsp;(default = 255, min 0, max 255): The green RGB value for the timer text.</span><br /><span style="font-size: 12px;"><strong>timerColourRGB_B</strong>&nbsp;(default = 255, min 0, max 255): The blue RGB value for the timer text.</span><br /><br /><br /></p>
